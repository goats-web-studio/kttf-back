# kttf-back

NestJS API. Отдельное приложение: свой контейнер, свой деплой. Фронтенд отсюда не раздаётся.

**Пока пусто.** Разворачивается после `kttf-shared/brackets` — см. `docs/05-state.md`.

Что здесь будет: модули домена (клубы, игроки, турниры, встречи, рейтинг), Prisma, аутентификация по SMS, синхронизация офлайн-операций.

Чего здесь не будет: расчёта рейтинга и генерации сеток. Они живут в `kttf-shared` и исполняются тем же кодом в браузере — бриф, запрет №2.

Архитектура и модель данных — `docs/03-tech-spec.md`. Контракт API — раздел 7 там же.
