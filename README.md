# kttf-back

NestJS API. Отдельное приложение: свой контейнер, свой деплой. Фронтенд отсюда не раздаётся.

Чего здесь не будет: расчёта рейтинга и генерации сеток. Они живут в `kttf-shared` и исполняются тем же кодом в браузере — бриф, запрет №2.

Архитектура и модель данных — `docs/03-tech-spec.md` в `kttf-shared`. Контракт API — раздел 7 там же.

## Запуск

Нужна поднятая инфраструктура: `cd ../kttf-infra && docker compose up -d`.

```
cp .env.example .env
pnpm install
pnpm db:migrate
pnpm build && pnpm start
```

Проверка: `curl http://localhost:3000/api/v1/health` → `{"status":"ok","database":"up"}`.

Разработка — `pnpm start:dev` (пересборка при изменениях) во втором терминале вместе с `pnpm start:watch`. Раздельно, потому что декораторы Nest требуют метаданных типов, а их выпускает только `tsc`.

## Команды

| Команда                  | Что                                |
| ------------------------ | ---------------------------------- |
| `pnpm lint`              | ESLint с type-aware правилами      |
| `pnpm typecheck`         | `tsc --noEmit`                     |
| `pnpm test`              | Vitest                             |
| `pnpm build`             | Сборка в `dist/`                   |
| `pnpm check:shared`      | Связка с общим кодом считает верно |
| `pnpm bump:shared <SHA>` | Обновление общего кода (ADR-010)   |

## Раскладка

```
src/
├── features/        Предметные области: по одной папке на область
├── infra/           Конфигурация и база — то, чем пользуются features
├── common/          Применяется ко всем запросам: фильтр ошибок, пайпы
└── generated/       Клиент Prisma. Артефакт генерации, в репозитории его нет
```

Структура по функциям, а не по типам файлов — бриф 3.2.

## Что уже есть

Каркас: конфигурация с проверкой окружения на старте, подключение к базе, единый формат ошибок (ТС 7.8), `GET /api/v1/health`.

Аутентификация по контракту ТС 7.1: `request-code`, `verify-code`, `refresh`, `logout`, `me`.

**Провайдер SMS не подключён** — ОВ-9 в `docs/05-state.md`. Код уходит в лог приложения:

```
[LogCodeSender] Код для +77015550101: 718400 (провайдер SMS не подключён)
```

Адаптер отказывается собираться при `NODE_ENV=production`: забыть подменить его при выкатке слишком легко, а цена забывчивости — вход в любой аккаунт по номеру телефона.

Домен клубов и игроков по контракту ТС 7.2 и 7.4: списки с поиском и постраничностью, карточки, создание и изменение, состав клуба с ролями.

Публично читается всё, кроме изменений. Права проверяются guard'ом по роли в клубе (ТС 8.3): владелец ведёт состав, организатор правит клуб и игроков, судья ни того, ни другого — по ТЗ 1 ему принадлежит турнир, а не клуб.

Чего ещё нет из этих разделов:

| Маршрут                                                    | Почему                                                                        |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `/players/:id/rating-history`, `/matches`, `/head-to-head` | Читают журнал рейтинга и встречи, которых до появления турниров не существует |
| `/clubs/:id/balance`, `/transactions`                      | Финансы клуба; оплата ждёт подтверждения гипотез                              |

Чего ещё нет вообще: турниров, консоли, `Dockerfile`. Порядок — `docs/05-state.md`.
